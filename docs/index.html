The Minimalism Protocol

A six-stage decision ladder that ensures agents reuse existing code instead of rewriting it

Stage 1

STOP

Does this need to exist?

Stage 2

QUERY

search_symbols + find_similar

Stage 3

CHECK

Does a dependency handle this?

Stage 4

STDLIB

Standard library covers it?

Stage 5

ASSESS

get_impact — smallest diff

Stage 6

WRITE

Only then: the minimum

Get Started in 3 Commands

Zero to full structural awareness in under a minute

Step 1 — Install

Install with all language support

pip install ast-intel[all,analysis,mcp]
Step 2 — Scan

Build the code graph (~8 seconds)

ast-intel scan /path/to/repo
Step 3 — Connect

Wire into your editor

ast-intel install copilot
# Or install from Git directly pip install "ast-intel[all,analysis,mcp] @ git+https://github.com/AstIntel/ast-intel.git" # Scan with specific options ast-intel scan /path/to/repo --include src/ --exclude "*/tests/*" --analyze # Start MCP server for editors ast-intel serve /path/to/repo --analyze --similarity # Auto-rebuild on every commit ast-intel hook install

Scan Command — Full Reference

Control exactly what gets indexed and what gets produced

ast-intel scan /path/to/repo [OPTIONS] # Scope control --include, -i PATH Include specific folders (repeatable) --exclude, -e PATH Exclude specific paths (repeatable) --lang, -l LANG Filter by language: rust, python, typescript, go, csharp, java, cpp # Output control --output, -o DIR Output directory (default: <repo>/ast_output/) --format, -f FORMAT Output format (see table below) # Analysis flags --analyze Run community detection + god node analysis --similarity Compute SIMILAR_TO edges (Jaccard structural similarity) --infra-scan Emit resources.json (cloud infrastructure inventory) # Performance & caching --workers, -w INT Parallel workers (default: CPU count) --no-cache Force full re-parse (skip incremental cache) --no-iac Skip IaC scanning (K8s, Helm, Docker, Terraform) --no-methods Skip package method call extraction # Viewer options --offline Inline vis.js/mermaid for self-contained HTML (no CDN) # Other --quiet, -q Suppress progress output (for CI) --debug Verbose logging to stderr --version Print tool version

.ast-intel-scan (Include File)

Place in repo root. One path per line — only these get scanned.

# .ast-intel-scan src/ lib/ services/ # Comments and blank lines are ignored

.ast-intel-ignore (Exclude File)

Place in repo root. Gitignore-compatible glob patterns.

# .ast-intel-ignore **/tests/** **/node_modules/** **/target/** **/dist/** *.generated.ts

Setting Up the Minimalism Protocol

Agent instructions that tell your coding AI to query the graph before writing code

AGENTS.md — for Codex, Claude Code, CodeWhale

Place in repo root. Read automatically by compatible agents on session start.

# AST-Intel — Minimalism-First Agent Mode You are a minimalist coding agent. You have access to a structural code graph via the ast-intel MCP server. ## The Protocol Before writing code, stop at the first rung: 1. **Does this need to exist?** → Skip it (YAGNI) 2. **Already in codebase?** → search_symbols / find_similar. If match: REUSE. 3. **Stdlib does it?** → Use it. No wrapper. 4. **Installed dep does it?** → Use it. 5. **One line?** → Make it one line. 6. **Only then:** write the minimum that works. ## Rules - No abstractions nobody asked for - Deletion over addition. Boring over clever. - get_impact before touching shared code - Mark shortcuts: # minimal: <reason> - Mark reuse: # reuse: <file:line>

# AST-Intel — Agent Instructions You have access to the ast-intel MCP server. Use it before writing new code. ## The Minimalism Protocol ### 1. STOP — Does this need to exist? ### 2. QUERY the graph Call search_symbols with the name of what you're about to write. Call find_similar if you have a reference. The graph is authoritative. ### 3. CHECK dependencies Call get_dependencies. If an installed package already exposes this, USE it. ### 4. CHECK stdlib coverage ### 5. ASSESS impact Call get_impact. If blast radius is large, prefer the SMALLEST correct diff. ### 6. Only then: write the minimum that works
